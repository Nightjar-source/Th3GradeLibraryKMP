طريقة صناعة "مؤشر الزجاج السائل" (Liquid Glass Pointer) في Jetpack Compose
========================================================================
هذه التقنية تسمح لك بإنشاء مؤشر (Indicator) داخل القائمة السفلية (Bottom Navigation) يتتبع حركة إصبع المستخدم بدقة وسلاسة عالية (كالماء) قبل أن يرفع إصبعه ليختار العنصر، مع التوافق التام مع اللغات التي تُقرأ من اليمين لليسار (RTL) مثل اللغة العربية.

### الفكرة البرمجية الأساسية:
1. نستخدم `pointerInput` على الحاوية الأب (الـ Row) لقراءة إحداثيات اللمس (X).
2. نستخدم `awaitPointerEventScope` لتتبع اللمسات المستمرة دون استهلاكها (بدون `change.consume()`) لضمان عدم تجميد الشاشة.
3. لمعالجة مشكلة اتجاه الواجهة في اللغة العربية (RTL)، نقوم بجلب اتجاه التخطيط الحالي (LayoutDirection) ونعكس المحور السيني (X) رياضياً لكي يتطابق مسار إصبع المستخدم مع حركة المؤشر البصرية.
4. نربط قيمة الإزاحة (Offset) للمؤشر بـ `animateDpAsState` مع حركة `spring` (زنبرك) لكي يلحق المؤشر بالإصبع بشكل سائل ومرن بدلاً من التخطي المباشر.
5. عند رفع الإصبع `!change.pressed`، نقوم باحتساب مكان توقف الإصبع برمجياً ونقوم بتفعيل النقر (Click) على العنصر الذي تم الوقوف عليه.

### الكود البرمجي (مثال قابل للنسخ):

```kotlin
// 1. حساب العرض الخاص بكل أيقونة
val contentWidth = maxWidth
val itemWidth = contentWidth / navItems.size
val itemWidthPx = with(LocalDensity.current) { itemWidth.toPx() }

// 2. حالة (State) لحفظ إحداثيات الإصبع أثناء السحب
var dragOffset by remember { mutableStateOf<Float?>(null) }

// 3. الأنيميشن السائل للمؤشر
val indicatorOffset by animateDpAsState(
    targetValue = if (dragOffset != null) {
        // إذا كان يلمس الشاشة، اجعل المؤشر يتمركز حول إصبعه
        with(LocalDensity.current) { (dragOffset!! - (itemWidthPx / 2)).toDp() }
    } else {
        // إذا لم يكن يلمس الشاشة، اجعل المؤشر يستقر على العنصر المختار
        itemWidth * selectedIndex
    },
    animationSpec = spring(dampingRatio = 0.6f, stiffness = Spring.StiffnessLow)
)

// 4. جلب اتجاه التخطيط للغة العربية (RTL)
val layoutDirection = LocalLayoutDirection.current

// 5. بناء القائمة السفلية مع تتبع اللمس
Row(
    modifier = Modifier
        .fillMaxSize()
        .pointerInput(layoutDirection) { // نضع الـ layoutDirection هنا ليعيد التحديث إذا تغيرت اللغة
            val isRtl = layoutDirection == androidx.compose.ui.unit.LayoutDirection.Rtl
            awaitPointerEventScope {
                while (true) {
                    val event = awaitPointerEvent()
                    val change = event.changes.firstOrNull()
                    if (change != null) {
                        if (change.pressed) {
                            // الإصبع يلمس أو يتحرك:
                            val rawX = change.position.x
                            // عكس الإحداثيات إذا كانت اللغة عربية
                            val directionalX = if (isRtl) size.width.toFloat() - rawX else rawX
                            dragOffset = directionalX.coerceIn(0f, size.width.toFloat())
                        } else {
                            // تم رفع الإصبع: تنفيذ النقر واختيار العنصر!
                            if (dragOffset != null) {
                                val idx = (dragOffset!! / itemWidthPx).toInt().coerceIn(0, navItems.lastIndex)
                                navItems[idx].third() // تنفيذ أمر النقر (onClick) الخاص بالعنصر
                                dragOffset = null     // إعادة تعيين المؤشر
                            }
                        }
                    }
                }
            }
        }
) {
    // محتويات الأيقونات (Icons) يتم وضعها هنا
}
```

### ملاحظات هامة عند استخدام التقنية:
- يتم إلغاء استخدام `clickable` من عناصر الأيقونات الفردية في الـ `Column` الخاص بكل أيقونة، لأننا نعالج النقر مركزياً في الـ `Row` الرئيسي عبر تتبع حركة الإصبع.
- استخدام `spring` هو السر الحقيقي في حركة المؤشر المطاطية (السائلة). إذا تم استخدام `tween` العادي، فستكون الحركة خطية وصلبة.
