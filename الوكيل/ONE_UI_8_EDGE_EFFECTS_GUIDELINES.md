# 📱 دليل تصميم تأثيرات الحواف وأمان الأزرار لواجهة Samsung One UI 8 (أندرويد 16)
## وثيقة إرشادية للمطور القادم — إعداد: الوكيل الذكي (Antigravity / Gemini)
**تاريخ الإصدار:** يونيو 2026

---

## 1. الخلفية التقنية (Context & Android 16 Standards)
ابتداءً من نظام **Android 15** ووصولاً إلى **Android 16 (API 36 - One UI 8)**، أصبحت الشاشات الممتدة من الحافة إلى الحافة (**Edge-to-Edge**) مفروضة إجبارياً على جميع التطبيقات. 
* شريط التنقل السفلي وشريط الحالة العلوي للنظام أصبحا **شفافين بالكامل** بشكل افتراضي.
* يطفو شريط الإيماءات السفلي (Gesture Handle) أو أزرار النظام الثلاثة مباشرة فوق محتوى التطبيق.
* **الخطر:** إذا لم يقم المطور بتهيئة تخطيط التطبيق، ستتداخل الأزرار التفاعلية للتطبيق مع شريط النظام، مما يعيق اللمس ويسبب تصادمات في تجربة المستخدم (UX).

---

## 2. المفهوم البصري: التلاشي الغيمي (The Cloudy Exit Concept)
بدلاً من حماية منطقة شريط التنقل السفلي باستخدام كتل لونية مصمتة (Solid Color Blocks) مثل المستطيلات السوداء أو الرمادية التي تقطع جمالية التصميم، نعتمد أسلوب **التلاشي الغيمي**:
1. **الخلفية الممتدة:** تمتد خلفية النافذة أو الكارت الملونة لتصل إلى الحافة الفعلية للشاشة خلف شريط النظام الشفاف.
2. **تلاشي المحتوى:** عند تمرير القوائم أو النصوص لأسفل، لا تختفي فجأة عند حافة قاسية، بل تتلاشى وتذوب تدريجياً داخل لون خلفية الواجهة (Gradient Blur).
3. **أمان منطقة اللمس:** يتم إزاحة الأزرار والعناصر التفاعلية ديناميكياً لتستقر بأمان فوق شريط الإيماءات.

---

## 3. الهيكل البرمجي القياسي في Jetpack Compose
لتحقيق هذا التأثير بشكل صحيح وتجنب الأخطاء الشائعة (مثل تجاهل أبعاد شريط النظام في وضعيات العرض المختلفة)، يجب اتباع الهيكل التالي:

### أ. كود الهيكل العام للنافذة المنبثقة (Modal/Bottom Sheet):
```kotlin
Box(
    modifier = Modifier.fillMaxSize(),
    contentAlignment = Alignment.BottomCenter
) {
    // 1. جسم النافذة (يمتد للخلفية كاملة بما فيها خلف شريط الإيماءات)
    Box(
        modifier = Modifier
            .fillMaxWidth()
            .clip(RoundedCornerShape(topStart = 28.dp, topEnd = 28.dp))
            .background(MaterialTheme.colorScheme.surface) // يمتد للحافة السفلية
    ) {
        // 2. محتوى الواجهة (يحتوي على مسافة أمان سفلي ديناميكية)
        Column(
            modifier = Modifier
                .fillMaxWidth()
                .verticalScroll(rememberScrollState())
                .padding(top = 24.dp, start = 24.dp, end = 24.dp)
        ) {
            // محتوى الإعدادات أو الأزرار هنا...
            
            // ⚠️ مسافة الأمان السفلي (تدفع المحتوى التفاعلي فوق خط الإيماءات)
            Spacer(modifier = Modifier.navigationBarsPadding().height(24.dp))
        }

        // 3. غطاء التلاشي الغيمي (Cloudy Transition Overlay)
        // يوضع في أسفل الكارت ليقوم بدمج المحتوى الممرر تدريجياً مع الخلفية
        Spacer(
            modifier = Modifier
                .fillMaxWidth()
                .align(Alignment.BottomCenter)
                .navigationBarsPadding() // يطابق ارتفاع شريط النظام
                .height(24.dp)           // يطابق مسافة الأمان الإضافية
                .background(
                    brush = Brush.verticalGradient(
                        colors = listOf(
                            Color.Transparent,                     // تلاشي يبدأ من الشفافية
                            MaterialTheme.colorScheme.surface       // ينتهي بلون الكارت بالكامل
                        )
                    )
                )
        )
    }
}
```

## 4. القواعد الذهبية لمنع الأخطاء المستقبلية (Golden Rules)

> [!WARNING]
> **تجنب دمج محددات الارتفاع المتضاربة:**
> إياك كتابة كود مثل: `Modifier.windowInsetsBottomHeight(WindowInsets.navigationBars).height(24.dp)`.
> في محرك Compose، المحدد الأخير يلغي الأول، مما سيجعل الارتفاع دائماً `24.dp` فقط وتجاهل شريط النظام، مما يسبب تداخل الأزرار مع نظام الملاحة.

> [!IMPORTANT]
> **استخدم `navigationBarsPadding()` دوماً للمحتوى التفاعلي:**
> أي زر، دائرة ألوان، أو حقل نصي يقع في الجزء السفلي من الشاشة يجب أن يُدفع للأعلى باستخدام `Modifier.navigationBarsPadding()` لضمان عدم تعارضه مع شريط إيماءات **One UI 8**.

> [!TIP]
> **التدرج اللوني المتطابق:**
> يجب أن ينتهي التدرج اللوني الرأسي (`Brush.verticalGradient`) دائماً بنفس اللون الفعلي للمكون الحاضن له (`MaterialTheme.colorScheme.surface` أو لون الخلفية الأسود الصريح في الوضع الليلي) لكي يذوب المحتوى داخله بشكل غير مرئي ويحقق النعومة الغيمية المطلوبة.
