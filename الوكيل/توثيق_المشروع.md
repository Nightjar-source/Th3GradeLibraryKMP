# توثيق مشروع Th3Grade Library KMP
## وثيقة للمطورين — إعداد: الوكيل الذكي (Antigravity / Gemini)
**تاريخ آخر تحديث:** يونيو 2026

---

## 1. نظرة عامة على المشروع

تطبيق مكتبة تعليمية متعدد المنصات مبني بـ **Kotlin Multiplatform (KMP)** مع **Jetpack Compose Multiplatform**.

| المعلومة | التفاصيل |
|---|---|
| الهيكل | KMP — shared + androidApp |
| واجهة المستخدم | Compose Multiplatform 1.7+ |
| نظام الألوان | Material You (Dynamic Colors) |
| الحد الأدنى لأندرويد | API 24 (Android 7) |
| الحد الأقصى المستهدف | API 36 (Android 16 — يونيو 2026) |

## 3. نظام التنقل (Navigation)

التنقل مدار بـ **state** داخل `App.kt` وليس بمكتبة Navigation خارجية:

```kotlin
var currentTab by remember { mutableStateOf("news") }   // التبويب الحالي
var webViewUrl by remember { mutableStateOf<String?>(null) }  // رابط WebView
```

### التبويبات الأربعة:
| المفتاح | الشاشة |
|---|---|
| `"news"` | آخر الأخبار |
| `"library"` | المكتبة |
| `"bookmarks"` | المحفوظات |
| `"settings"` | الإعدادات |

### فتح خبر (WebView):
- الضغط على بطاقة خبر → يضبط `webViewUrl` → تظهر شاشة WebView كاملة
- الرجوع → يعيد `webViewUrl = null` → يعود لشاشة الأخبار
- **ملاحظة:** WebView هو شاشة منفصلة كاملة (Full Screen) وليس Dialog أو BottomSheet

## 4. نظام المزامنة (SyncEngine)

**الملف:** `shared/.../network/SyncEngine.kt`

### كيف يعمل:
```
التطبيق يفتح → يقرأ lastFetchedLink (آخر رابط جُلب)
              → يجلب RSS Feed
              → يقارن الروابط الجديدة مع lastFetchedLink
              → يحفظ الجديد فقط
              → يحدّث lastFetchedLink بالأحدث
              → يرسل إشعاراً إذا كان هناك جديد
```

### التخزين المنفصل:
| البيانات | مكان الحفظ |
|---|---|
| `lastFetchedLink` | SharedPreferences مستقلة (watermark فقط) |
| قائمة الأخبار | SharedPreferences منفصلة (cache الأخبار) |
| إعدادات المستخدم | SharedPreferences منفصلة |

### خيارات وقت المزامنة:
| الخيار | الوقت |
|---|---|
| `on_open` | عند فتح التطبيق فقط (بدون خلفية) |
| `30m` | كل 30 دقيقة |
| `1h` | كل ساعة (الافتراضي) |
| `12h` | كل 12 ساعة |
| `24h` | كل 24 ساعة |

**مهم:** الوقت يُحسب من لحظة الضبط وليس من رأس الساعة.

## 5. المزامنة في الخلفية (WorkManager)

**الملف:** `androidApp/.../MainActivity.kt` — دالة `scheduleBackgroundSync()`

- تستخدم **WorkManager** (الطريقة الرسمية لجوجل)
- تقرأ إعداد المستخدم `syncInterval` عند كل إعادة جدولة
- عند تغيير المستخدم للإعداد: `CANCEL_AND_REENQUEUE` — تلغي القديم وتبدأ من جديد
- الحد الأدنى في WorkManager: **15 دقيقة** (قيد النظام)
- شرط: يعمل فقط عند توفر إنترنت وبطارية غير منخفضة

## 6. الإشعارات

### الأذونات:
| الإصدار | السلوك |
|---|---|
| أندرويد 13+ (API 33+) | يطلب إذن `POST_NOTIFICATIONS` عند أول فتح |
| أندرويد 12 وما قبل | الإشعارات مفعّلة تلقائياً عند التثبيت |

### شريط تنبيه "الإشعارات معطلة":
يظهر في شاشة الأخبار أسفل شريط العنوان مباشرة وفوق البطاقات إذا كانت الإشعارات مغلقة.

**تصميم الشريط:**
```
┌─────────────────────────────────────────┐
│ 🔔  الإشعارات معطلة           [تفعيل] │
│     فعّل لتصلك أخبار عاجلة فور نشرها  │
└─────────────────────────────────────────┘
```
- **الخلفية:** `errorContainer` (يتكيف مع الثيم الفاتح والمظلم والديناميكي)
- **النص:** `onErrorContainer`
- **الزوايا:** 16dp مدوّرة
- **الارتفاع:** ~58dp
- **الهوامش:** 12dp جانبية، 6dp عمودية
- **الحركة:** ينزل من الأعلى بـ `slideInVertically`

### منطق زر "تفعيل" (ضغطة واحدة فقط):
```
أندرويد 13+:
  └─ لم يرفض بعد / رفض مرة واحدة → نافذة النظام المنبثقة ✅
  └─ رفض نهائياً → صفحة إشعارات التطبيق ⚙️
أندرويد أقدم (سامسونج، هواوي، شاومي، أوبو...):
  └─ المحاولة 1: ACTION_APP_NOTIFICATION_SETTINGS
  └─ المحاولة 2: ACTION_APPLICATION_DETAILS_SETTINGS
  └─ المحاولة 3: ACTION_MANAGE_APPLICATIONS_SETTINGS
```

## 10. الصلاحيات (Permissions)

**المبدأ: أقل صلاحية ممكنة**

```xml
<!-- AndroidManifest.xml -->
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />  <!-- Android 13+ فقط -->
<!-- RECORD_AUDIO يُطلب عند الضغط على البحث الصوتي فقط -->
```

| الصلاحية | السبب | متى تُطلب |
|---|---|---|
| INTERNET | جلب الأخبار | تلقائية |
| ACCESS_NETWORK_STATE | فحص الإنترنت قبل الجلب | تلقائية |
| POST_NOTIFICATIONS | إرسال إشعارات الأخبار | أول فتح (Android 13+) |
| RECORD_AUDIO | البحث الصوتي | عند الضغط على أيقونة الميكروفون |

## 11. مشاكل شائعة وحلولها (يونيو 2026)

| المشكلة | السبب | الحل |
|---|---|---|
| `outOfBoundsPageCount` لا يُعرف | أُزيل في Compose 1.7+ | احذف المعامل |
| `collectAsState` لا يُعرف | يحتاج import صريح | `import androidx.compose.runtime.collectAsState` |
| `composed` لا يُعرف | يحتاج import صريح | `import androidx.compose.ui.composed` |
| `beyondBoundsPageCount` | اسم قديم | استبدله بـ `outOfBoundsPageCount` ثم احذفه |
| خطأ Kotlin daemon | WorkManager يستهلك ذاكرة | `./gradlew --stop` ثم أعد البناء |
